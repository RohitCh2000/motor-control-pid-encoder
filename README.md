# Motor Control — PID & Encoder Feedback
Embedded C++ motor-control and speed-regulation module using PWM, PID control and wheel-encoder feedback, designed to improve wheel-speed synchronization under varying payload conditions.

Personal project based on professional AMR motor-control experience (no employer code).

## Features
- PID speed regulation with encoder feedback
- PWM output configuration
- Test harness for tuning and step-response checks

## Tech
Embedded C++, PWM, PID, Encoders, RTOS concepts
